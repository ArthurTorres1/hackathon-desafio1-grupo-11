# Roteiro de demonstração ForestTrace

O roteiro de apresentação vigente está em [presentation-demo.md](presentation-demo.md). Ele reúne sequência de slides, fala sugerida, percurso ao vivo de três minutos, checklist de preparação e respostas para perguntas comuns.

Os dados usados são sintéticos, identificados como `SIMULADA`, e os passaportes permanecem `MISSING_EVIDENCE`. A rota candidata AM→SP e os requisitos normativos continuam pendentes; não apresente a demo como validação oficial, DDS ou certificação.

Para detalhes técnicos e evidências de execução, consulte [delivery-2026-11-06.md](delivery-2026-11-06.md), [validation-2026-11-06.md](validation-2026-11-06.md) e [external-dependencies.md](external-dependencies.md).
