## Usar e recuperar

A instância empacotada conferida nesta sessão está em http://127.0.0.1:3001. Para uma inicialização posterior com a porta padrão, siga o README: banco, migrações, seed e `docker compose --profile app up --build -d app`. Preserve .env existente. A pasta data/private é compartilhada com a imagem; banco e documentos não fazem parte do código público.

`npm run check:delivery -- http://127.0.0.1:3001` confere a instância. `npm run backup:demo` gera backup privado. `npm run restore:demo -- data/backups/PASTA` restaura em banco novo, sem sobrescrever a aplicação.
